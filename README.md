# JavaScript Express.js server

A basic Express.js server with a static home page and a JSON API.

## Local development

Install dependencies:

```bash
npm ci
```

Start the server:

```bash
npm start
```

The server listens on port 3000 by default. Set the `PORT` environment variable to use another port.

## Tests

```bash
npm test
```
